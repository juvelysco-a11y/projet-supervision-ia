# Projet Supervision IA
Détection d'anomalies sur le trafic réseau : seuil fixe, z-score, Isolation Forest.

## Installation
python -m venv env
env\Scripts\activate
pip install -r requirements.txt

## Ordre des scripts
01 générer les données, 02 explorer, 03 à 05 les trois méthodes,
06 comparaison, 07 données réelles (NAB), 08 réglages.
